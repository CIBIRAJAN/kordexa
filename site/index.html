What is Kordexa?

/kordexa --describe

Kordexa is a local learning system that runs in the coding agent you already use. It captures your profile, target role and first skill, then writes an adaptive plan with a fixed 30-day minimum, installs adapters for your agents, and turns each day into one build artifact with visible proof. There is no account, no dashboard and no subscription.

Kordexa builds on the open-source EduOrchestrate CLI by Haroon K M. Commands on this site use its published npm package.

Turn any AI coding CLI into a learning command center.

          Frequently asked

          How is the daily plan chosen?

          It starts from your target role, first skill and requested length. Topics matching your skill move to the front, and plans never go below 30 days.

          Does it send email without asking every day?

          Only after you set it up. send-today --dry-run is a safe preview, and scheduled sends use the GitHub Actions workflow with your own SMTP secrets.

          Does a browser or agent need to stay open?

          No. The scheduled workflow runs on GitHub Actions, so the email can go out with your laptop shut.

          Where does my data go?

          Plans, digests, logs and cards are written to data/ in your project, which is git-ignored. The configurator on this page runs entirely in your browser.

          Which agents does it support?

          Claude Code, Codex and other AGENTS.md agents, Gemini, OpenClaw, Antigravity, Hermas and MCP-capable clients.
