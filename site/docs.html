Kordexa docs

Kordexa turns a target job role into a daily learning loop inside the AI coding agent you already use. Each day is one topic, one build artifact and one review.

  • MIT
  • Node 18+
  • 0 runtime dependencies
  • 7 agent targets
About the command name. Kordexa builds on EduOrchestrate. Until a kordexa package is published, install and run it with npx eduorchestrate, as shown throughout these docs.

Quickstart

Run the guided setup from a terminal in your project:

npx eduorchestrate

For a scripted setup, pass your answers as flags. The plan configurator can write this command for you.

npx eduorchestrate --yes --name "Ada" --email "ada@example.com" \
  --role "Agentic AI and LLM Engineer" --skill "evaluation" --days 45

Then preview your first daily email. A dry run never sends anything.

npx eduorchestrate send-today --dry-run

What setup writes

  • eduorchestrate.config.json with your profile and schedule
  • Adapter files for each supported agent
  • data/30-day-plan.json, the harness, learning sources and first research digest
  • .github/workflows/eduorchestrate-daily.yml for scheduled delivery
  • .env.local with SMTP settings, plus .gitignore entries

Daily workflow

A typical day runs from loading context to logging proof:

npx eduorchestrate harness
npx eduorchestrate status
npx eduorchestrate research --day 8
npx eduorchestrate send-today --dry-run
npx eduorchestrate log-progress --day 8 --completed "Built search demo" \
  --evidence "github.com/me/search-demo" --minutes 90 --confidence 4
npx eduorchestrate progress-card
  1. Load the harness. It tells the agent what to load and what to keep out of chat.
  2. Check status. See the active day, next action and momentum.
  3. Research. Write a dated digest with docs, a top video and a top repo.
  4. Build. Complete the day's single artifact.
  5. Log evidence. Record what you finished, with a link to the proof.
  6. Render progress. Update your progression card.

Email and scheduling

Setup writes a GitHub Actions workflow that sends the day's email at your chosen time. It calculates the day from schedule.startDate and skips sending with plan-complete once the plan ends.

VariablePurpose
SMTP_HOSTSMTP server hostname
SMTP_PORT465 for implicit TLS, 587 for STARTTLS
SMTP_USERSMTP username
SMTP_PASSSMTP password or app password
SMTP_FROMFrom address for daily emails

Keep these in .env.local for local sends. For scheduled sends, print the GitHub secret commands with:

npx eduorchestrate setup-secrets

Troubleshooting

Start with the built-in check:

npx eduorchestrate doctor
SymptomFix
Scheduled email never arrivesRun setup-secrets, set all five SMTP_* secrets, and confirm the workflow is enabled.
send-today skips with plan-completeThe plan has ended. Run recommend-next, then plan with a new --skill.
A shorter plan came back with 30 daysThis is expected. The 30-day minimum is fixed.
Links show searches instead of resultsThe lookup ran offline or was rate limited. Run it again online.
Email works locally but not in ActionsActions can't read .env.local. Add the values as GitHub secrets.
